# SteamP2PInfo planning documents

These documents record the 25 July 2026 documentation-only audit and improvement plan:

- [Upstream issue audit](UPSTREAM_ISSUE_AUDIT.md) — all 52 original issues, their upstream disposition, the revised application's static status, and required verification.
- [Application improvement roadmap](IMPROVEMENT_ROADMAP.md) — release gates, stability work, future updates, test strategy, and sequencing.
- [WinUI 3 migration plan](WINUI3_MIGRATION_PLAN.md) — the v1.5 feature-parity contract, architecture, phases, deployment choices, and cutover checklist.
- [Discoverability plan](DISCOVERABILITY_PLAN.md) — README positioning, GitHub description/topics, search intent, content backlog, measurement, and the website decision.

Static inspection cannot prove live Steam, game, overlay, ETW, or WFP behaviour. Runtime checks in these plans are acceptance criteria, not claims that the current build has passed them.
